# Checklist: развитие ChatBot

## 1. Регистрация и авторизация пользователей

- [ ] Спроектировать отдельный auth-сервис.
- [ ] Выбрать стек для auth-сервиса: FastAPI/Flask, база данных, JWT или cookie-сессии.
- [ ] Добавить регистрацию по email и паролю.
- [ ] Добавить вход по email и паролю.
- [ ] Добавить безопасное хеширование паролей.
- [ ] Добавить проверку уникальности email.
- [ ] Добавить endpoint проверки текущего пользователя.
- [ ] Добавить logout/отзыв сессии, если используется cookie/session подход.
- [ ] Добавить базовые тесты регистрации и авторизации.
- [ ] Подключить auth-сервис к Docker Compose.

## 2. Самостоятельный чат-бот вместо VK-бота

- [x] Проанализировать текущую логику `bot.py` и отделить бизнес-логику от VK API.
- [x] Выделить модуль обработки сообщений, который не зависит от VK.
- [ ] Создать backend API для собственного чат-бота.
- [ ] Добавить endpoint отправки сообщения пользователем.
- [ ] Добавить endpoint получения ответа бота.
- [ ] Сохранить текущие функции расписания и профилей пользователей.
- [ ] Перенести хранение пользовательских данных из VK-id на внутренние user-id.
- [ ] Добавить обработку ошибок и понятные ответы бота.
- [ ] Добавить тесты для основных сценариев диалога.

## 3. Nginx как точка входа

- [ ] Добавить сервис `nginx` в Docker Compose.
- [ ] Создать конфигурацию Nginx.
- [ ] Настроить проксирование frontend.
- [ ] Настроить проксирование API чат-бота.
- [ ] Настроить проксирование auth-сервиса.
- [ ] Добавить healthcheck-и для сервисов.
- [ ] Проверить запуск всего приложения через единый HTTP-вход.

## 4. Frontend для чат-бота

- [ ] Выбрать стек frontend: Vite/React или простой HTML/CSS/JS.
- [ ] Создать страницу входа и регистрации.
- [ ] Создать основной экран чата.
- [ ] Добавить отправку сообщений в backend API.
- [ ] Добавить отображение истории сообщений.
- [ ] Добавить состояния загрузки и ошибок.
- [ ] Добавить сохранение авторизации на стороне клиента.
- [ ] Адаптировать интерфейс под мобильные экраны.
- [ ] Подключить frontend к Docker Compose.

## 5. Запуск и тестирование

- [ ] Обновить `.env.example` под новые сервисы.
- [ ] Обновить `README.md` с инструкциями запуска.
- [ ] Запустить приложение через Docker Compose.
- [ ] Проверить регистрацию нового пользователя.
- [ ] Проверить авторизацию существующего пользователя.
- [ ] Проверить отправку сообщения чат-боту.
- [ ] Проверить получение ответа от чат-бота.
- [ ] Проверить работу через Nginx.
- [ ] Проверить логи сервисов.
- [ ] Зафиксировать найденные ошибки и исправить их.

## Предлагаемый порядок работы

1. Сначала отделить логику бота от VK.
2. Затем создать backend API чат-бота.
3. После этого добавить auth-сервис.
4. Затем подключить frontend.
5. В конце собрать все через Nginx и Docker Compose.
