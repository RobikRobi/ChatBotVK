# Настройка загрузки расписания из Google Таблиц

Этот документ описывает процесс настройки бота для загрузки расписания из Google Таблиц.

## Преимущества использования Google Таблиц

- **Оперативное обновление**: Заместитель директора может вносить изменения в расписание в реальном времени
- **Доступность**: Все участники чата получают актуальное расписание без перезапуска бота
- **Удобство**: Работа через привычный интерфейс Google Sheets
- **Коллаборация**: Несколько человек могут одновременно редактировать расписание

## Шаг 1: Создание сервисного аккаунта Google

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите API:
   - Google Sheets API
   - Google Drive API
4. Создайте сервисный аккаунт:
   - Перейдите в "IAM и администрирование" → "Сервисные аккаунты"
   - Нажмите "Создать сервисный аккаунт"
   - Укажите имя (например, "School Schedule Bot")
5. Создайте ключ для сервисного аккаунта:
   - Выберите созданный аккаунт
   - Перейдите на вкладку "Ключи"
   - Нажмите "Добавить ключ" → "Создать новый ключ"
   - Выберите формат JSON
   - Скачайте файл ключа

## Шаг 2: Подготовка Google Таблицы

1. Создайте новую Google Таблицу или используйте существующую
2. Скопируйте ID таблицы из URL:
   - URL имеет вид: `https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit`
   - `SPREADSHEET_ID` - это длинная строка символов
3. Структура таблицы должна соответствовать формату:
   ```
   |        | A       | B      | C        | D        | E        |
   |--------|---------|--------|----------|----------|----------|
   | 1      |         | Звонки | 5А       | 5Б       | 6А       |
   | 2      |         | 08:30  | Математика| Русский  | Физика   |
   | 3      |         | 09:25  | Физика   | Математика| История  |
   | ...    |         | ...    | ...      | ...      | ...      |
   | 10     |         |        |          |          |          |
   | 11     | Понедельник| 08:30 | ...      | ...      | ...      |
   ```
   
   Или с названиями дней в первой колонке:
   ```
   |        | A         | B      | C        | D        |
   |--------|-----------|--------|----------|----------|
   | 1      |           | Звонки | 5А       | 5Б       |
   | 2      | Понедельник| 08:30 | Математика| Русский  |
   | 3      |           | 09:25 | Физика   | Математика|
   | ...    |           | ...    | ...      | ...      |
   | 10     | Вторник   | 08:30 | ...      | ...      |
   ```

4. Откройте доступ для сервисного аккаунта:
   - Нажмите кнопку "Настройки доступа" (Share)
   - Вставьте email сервисного аккаунта (вида `your-bot-name@project-id.iam.gserviceaccount.com`)
   - Предоставьте права "Читатель" (Viewer)

## Шаг 3: Настройка файлов проекта

1. Поместите скачанный JSON-файл с ключами в корень проекта:
   ```bash
   mv ~/Downloads/your-key-file.json /workspace/credentials.json
   ```

2. Добавьте переменные окружения в файл `.env`:
   ```
   VK_TOKEN=ваш_токен_vk
   VK_GROUP_ID=id_группы_vk
   GOOGLE_SPREADSHEET_ID=id_вашей_таблицы
   GOOGLE_CREDENTIALS_FILE=credentials.json
   ```

   Или укажите абсолютный путь к файлу ключей:
   ```
   GOOGLE_CREDENTIALS_FILE=/path/to/your/credentials.json
   ```

## Шаг 4: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 5: Запуск бота

```bash
python bot.py
```

При запуске бот попытается загрузить расписание из Google Таблицы. Если это не удастся, он автоматически переключится на локальный xlsx-файл.

## Формат таблицы

Таблица должна иметь следующую структуру:

- **Первая строка**: Заголовки с названиями классов (начиная с колонки C)
- **Вторая колонка (B)**: Время уроков (или слово "Звонки" в заголовке)
- **Колонки C и далее**: Предметы для каждого класса
- **Разделение по дням**: 
  - Пустые строки между днями, ИЛИ
  - Названия дней ("Понедельник", "Вторник" и т.д.) в первой колонке

Пример структуры:

```
|        |        | 5А            | 5Б            | 6А            |
|--------|--------|---------------|---------------|---------------|
|        | Звонки |               |               |               |
|        | 08:30  | Математика    | Русский язык  | Физика        |
|        | 09:25  | Физика        | Математика    | История       |
|        | 10:20  |               |               |               |
| Понедельник| 08:30  | ...           | ...           | ...           |
```

## Обновление расписания

Для обновления расписания:
1. Заместитель директора открывает Google Таблицу
2. Вносит необходимые изменения
3. Изменения сохраняются автоматически
4. При следующем запросе пользователи получат актуальное расписание

**Важно**: Бот загружает расписание при старте. Для применения изменений необходимо перезапустить бота.

## Возможные проблемы и решения

### Ошибка "Файл с ключами не найден"
- Проверьте, что файл `credentials.json` находится в корне проекта
- Или укажите правильный путь в переменной `GOOGLE_CREDENTIALS_FILE`

### Ошибка "Доступ запрещён"
- Убедитесь, что email сервисного аккаунта добавлен в доступ к таблице
- Проверьте, что включены Google Sheets API и Google Drive API

### Ошибка "Не удалось найти строку с классами"
- Проверьте структуру таблицы
- Убедитесь, что во второй колонке есть время или слово "Звонки"
- Проверьте, что названия классов указаны в первой строке

### Расписание не обновляется
- Бот загружает расписание при старте
- После изменений в таблице перезапустите бота

## Дополнительные возможности

### Несколько листов в одной таблице
Можно создать отдельные листы для разных недель или четвертей. Для этого укажите имя листа в коде или добавьте параметр `worksheet_name` в функцию `load_schedule_from_google`.

### Автоматическая перезагрузка
Для автоматической перезагрузки расписания можно добавить периодическую проверку изменений в таблице.
